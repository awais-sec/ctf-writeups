# CTF Writeups

A collection of **Capture The Flag and TryHackMe writeups** documenting practical cybersecurity problem-solving, investigation techniques, tools, commands, and lessons learned.

This repository is being built from previously maintained study notes. Writeups will be added progressively as they are reviewed and organized.

## Focus Areas

- SOC and security operations
- Digital forensics and investigation
- Network security and analysis
- Linux fundamentals
- Penetration testing
- Practical security tooling and command-line techniques

## Writeup Structure

Each completed writeup is intended to document:

1. **Challenge / room overview** — objective and scope
2. **Approach** — reasoning and investigation path
3. **Tools and commands** — relevant techniques used
4. **Findings / solution** — important results and observations
5. **Key takeaways** — what the exercise reinforced or taught

## Learning Workflow

```text
Challenge / Room
       ↓
Reconnaissance / Enumeration
       ↓
Analysis & Investigation
       ↓
Testing / Exploitation (where applicable)
       ↓
Evidence / Findings
       ↓
Solution & Lessons Learned
```

## Status

Writeups are currently being migrated and organized from existing notes. This repository will grow as individual rooms are reviewed rather than publishing incomplete material in bulk.
